# Student Q&A & Feedback System

A complete question and feedback system for students and instructors.

## Files

- `index.html` - Main webpage
- `style.css` - Styling
- `app.js` - Frontend logic
- `Code.gs` - Google Apps Script backend
- `logo.png` - Your logo image (optional)

## Setup

1. Create a Google Sheet
2. Open Tools > Script Editor
3. Copy `Code.gs` into the script editor
4. Deploy as Web App
5. Copy the Web App URL
6. Paste URL in `app.js` (replace `API_URL`)
7. Host HTML files on GitHub Pages or any web server
8. Upload `logo.png` to the same folder

## Features

- 📝 Students submit questions with files
- 📋 Students check feedback using ID + email
- 👨‍🏫 Instructor dashboard with statistics
- 📊 View all submissions with status
- 💬 Provide feedback with optional attachments
- 🔑 Password change from the page
